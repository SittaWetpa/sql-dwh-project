# Data Warehouse and Analytics Project

Welcome to the Data Warehouse and Analytics Project repository. This portfolio project showcases an end-to-end data warehousing and analytics solution—spanning database construction to actionable insight generation—while highlighting industry best practices in data engineering and analytics.

---

## 🚀 Project Requirements

### 🏗️ Data Engineering: Data Warehouse Construction

#### **Objective**
Develop a modern, centralized data warehouse using SQL Server to integrate siloed enterprise data (ERP and CRM systems) and establish a single source of truth for analytical reporting.

#### **Core Specifications**
* **Data Ingestion:** Extract and stage raw CSV datasets sourced from multiple operational systems (ERP and CRM).
* **Data Cleansing:** Standardize schema formats and resolve data quality anomalies prior to downstream consumption.
* **Integration & Modeling:** Consolidate disparate sources into an optimized, user-friendly data model engineered for high-performance analytical queries.
* **Scope & Historization:** Deliver a current-state analytical layer; historical tracking (SCD) is out of scope.
* **Documentation & Governance:** Maintain comprehensive data model documentation to align business stakeholders and technical teams.
